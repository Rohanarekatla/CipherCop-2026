Rules from the organisers' email: upload to the shared Google Drive folder by 20 Nov 2026, 11:59 PM IST. Files uploaded after that may not be considered.

The `submission/` folder holds only what goes to the Drive, one subfolder per Drive folder:

| Drive folder | File in this repo |
|---|---|
| Source code | `submission/1_Source_Code/CipherCop2026_AI-vengers_SourceCode.zip` (the whole repo; root `README.md` says how to run it) |

## Honest limits to say out loud

- Only one replay event (31 Aug to 2 Sep 2024) has full previous-runs forecasts.
- Officer and team rosters are assumptions until GHMC or police data is available.
- Building exposure is a ranking, not a flood prediction. Heights are model estimates.
- FireSight demo buildings are generated; only its feature weights are reused.
- The Claude agent path was not tested with a real API key; the local Llama path was.
