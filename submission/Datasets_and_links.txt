# Datasets used

Small snapshots are committed in `data/` and `Malik/data/` so the app runs offline. Large or live sources are linked below.

## Committed in this repo

| File | What | Source |
|---|---|---|
| `data/base.json` | 49 police stations, 8 fire stations, 51 underpasses, the Musi, 1 km cells, OSRM travel times, Musi thresholds | OpenStreetMap (Overpass API), OSRM |
| `data/hand.json` | 7,021 cells of 250 m: elevation, HAND, drainage, plus 260 OSM nalas | AWS Terrarium elevation tiles (SRTM-based), OpenStreetMap |
| `data/replay/2024-09-01.json` | Forecasts as issued 1 to 3 days before the 31 Aug to 2 Sep 2024 event, ERA5 observed rain, Musi discharge | Open-Meteo Previous Runs, Archive and Flood APIs |
| `data/calibration.json`, `data/backtest-samples.json` | 2024 and 2025 monsoon backtest output | generated by `scripts/backtest.js` |
| `data/intake-eval.json`, `test/fixtures/intake-eval.json` | AI triage evaluation on held-out English, Telugu, Hindi, Urdu messages | written by the team |
| `data/buildings.json`, `data/waterlogging.json` | 11,659 buildings and 23 waterlogging points for the Musi pilot corridor | built from `Malik/data` by `scripts/build-buildings.py` |
| `data/water.json` | 205 lakes, 55 culverts, buildings inside lake and nala buffers, 2,058 hospitals, clinics, schools and anganwadis | OpenStreetMap (Overpass API), `scripts/fetch-water.js` |
| `data/tgrac/*.json` | **Government data:** GHMC's 23 major waterlogging points, 1,162 surveyed nala segments with existing and proposed widths, 96 nalas, 847 tanks, 6 GHMC zones | Telangana Remote Sensing Applications Centre public GIS (https://tgrac.telangana.gov.in/arcgis/rest/services/GHMCNalas_Folder/GHMCNalas_vul/MapServer), `scripts/fetch-tgrac.js` |
| `data/sachet.json` | Latest official CAP alerts (IMD and other agencies), refreshed hourly by a GitHub Action | NDMA SACHET public RSS (https://sachet.ndma.gov.in/cap_public_website/rss/rss_india.xml), `scripts/fetch-sachet.js` |
| `Malik/data/` | Full AI-NETRA-GEO datasets: footprints, heights, river polygons, distances, waterlogging points, Sentinel-1 evidence | see below |
| `Aditya/data/` | FireSight demo data. **Generated, not real.** Only `model.json` importances are reused | generated by the team |

## External sources (links)

- Open-Meteo Ensemble API (GFS, ECMWF IFS, ICON-EPS, ECMWF AIFS): https://open-meteo.com/en/docs/ensemble-api
- Open-Meteo Previous Runs API: https://open-meteo.com/en/docs/previous-runs-api
- Open-Meteo Historical (ERA5) API: https://open-meteo.com/en/docs/historical-weather-api
- Open-Meteo Flood API (GloFAS river discharge): https://open-meteo.com/en/docs/flood-api
- OpenStreetMap, via Overpass: https://overpass-api.de (ODbL, attribution required)
- AWS Terrain Tiles (Terrarium): https://registry.opendata.aws/terrain-tiles/
- OSRM routing: https://project-osrm.org
- Google Open Buildings 2.5D Temporal (heights, via Earth Engine): https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_Research_open-buildings-temporal_v1
- Telangana TGRAC waterlogging points (ArcGIS REST): https://tgrac.telangana.gov.in/arcgis/rest/services/GHMCNalas_Folder/GHMCNalas_vul/MapServer/1
- Copernicus Sentinel-1 GRD (radar change experiment, Oct 2020): https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S1_GRD
- NDMA SACHET CAP alerts (planned): https://sachet.ndma.gov.in/cap_public_website/rss/rss_india.xml

## Caveats

Proximity to the Musi or a waterlogging point is not evidence of flooding. Building heights are model estimates. The TGRAC layer holds named points with no dates or depths. Officer and team rosters are assumptions until department data is available.
